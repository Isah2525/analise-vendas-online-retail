# Base de Dados — Online Retail

## 1. Origem dos dados

O projeto utiliza o dataset Online Retail, disponibilizado pelo UCI Machine Learning Repository.

**Fonte oficial:** https://archive.ics.uci.edu/dataset/352/online+retail

## 2. Características da base

| Característica | Descrição |
|---|---|
| Dataset | Online Retail |
| Instituição | UCI Machine Learning Repository |
| Registros originais | 541.909 |
| Período | 01/12/2010 a 09/12/2011 |
| País de origem da empresa | Reino Unido |
| Moeda | Libra esterlina (£) |
| Formato original | Excel |

## 3. Descrição das colunas

| Campo | Descrição |
|---|---|
| InvoiceNo | Identificador da nota fiscal ou pedido |
| StockCode | Código do produto |
| Description | Descrição do produto |
| Quantity | Quantidade de itens da transação |
| InvoiceDate | Data e horário da transação |
| UnitPrice | Preço unitário do produto |
| CustomerID | Identificador do cliente |
| Country | País do cliente |

## 4. Observações sobre os dados

A base apresenta algumas características importantes para a análise:

- Valores ausentes em determinados campos.
- Quantidades negativas, que podem estar relacionadas a devoluções.
- Notas fiscais de cancelamento identificadas pelo prefixo "C" em InvoiceNo.
- Registros com preço unitário igual a zero.

Essas ocorrências foram consideradas durante a exploração e preparação dos dados.

## 5. Obtenção da base

Para reproduzir o projeto:

1. Acesse o site oficial do UCI Machine Learning Repository.
2. Localize o dataset Online Retail.
3. Faça o download do arquivo disponibilizado.
4. Importe a base no Power BI Desktop.

**Link para acesso:** https://archive.ics.uci.edu/dataset/352/online+retail
